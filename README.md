## Basic guidelines for block diagram integration on github, markdown etc

This guide describes briefly how to add diagrams into markdown files using mermaid or svg files.

It is not intended as a comprehensive guide, but a starting point, there are many other ways to add diagrams in github (using artifacts, etc).

It provides a simple example of what bad, better and good diagrams are.

Check [diagrams_examples.md](./diagrams_examples.md)
